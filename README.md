# হিসাবঘর (Hisabghor)

Hisabghor is a free, browser-based Bengali toolkit for common calculations in Bangladesh. It works without sign-up or app installation.

## Tools

- **Bangla Date Converter**: Convert between Gregorian dates and Bangla dates (Bangabda).
- **Land Measurement Converter**: Convert between shotok, katha, bigha, acre, hectare, square feet, and square meters.
- **SSC / HSC GPA Calculator**: Calculate GPA from subject marks, including the fourth-subject rule.

## Usage

Open `index.html` in a web browser and choose a tool. No build step or dependency installation is required.

## Project Structure

- `index.html` - Homepage and tool links
- `bangla-date-converter.html` - Bangla date converter
- `land-calculator.html` - Land measurement converter
- `gpa-calculator.html` - SSC / HSC GPA calculator
- `style.css` - Shared styles
- `CNAME` - Custom domain configuration
- `robots.txt` and `sitemap.xml` - Search engine configuration
